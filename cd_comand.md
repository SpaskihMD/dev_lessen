# 📂 Команда `cd` в Linux

Команда `cd` (от англ. *change directory*) используется для перемещения между каталогами в терминале. Без неё навигация по файловой системе практически невозможна.

## 🧱 Базовый синтаксис

```bash
cd [путь_к_каталогу]
```

- Если путь не указан — переходит в **домашнюю директорию** пользователя (`/home/username`).
- После успешного перехода вы оказываетесь внутри указанной папки.

## 🧭 Специальные обозначения путей

| Обозначение | Значение | Пример |
|-------------|----------|--------|
| `.` | Текущая директория | `cd ./folder` (редко нужно явно) |
| `..` | Родительская директория (на уровень выше) | `cd ..` |
| `~` | Домашняя директория текущего пользователя | `cd ~/Documents` |
| `-` | Предыдущая директория (туда, где были до последнего `cd`) | `cd -` |
| `/` | Корень файловой системы | `cd /` |

## 📌 Самые частые примеры

```bash
# Перейти в домашнюю папку
cd
cd ~

# Подняться на один уровень вверх
cd ..

# Подняться на два уровня вверх
cd ../..

# Вернуться в предыдущую папку
cd -

# Перейти в папку с пробелом в имени
cd "My Documents"
cd My\ Documents

# Перейти в подпапку относительно текущей
cd Documents/Projects

# Перейти из любого места в /var/log
cd /var/log
```

## 🧠 Как работает `cd` с путями

### Абсолютный путь
Начинается с `/` — от корня всей системы.
```bash
cd /home/user/Downloads
cd /etc/nginx
```

### Относительный путь
Начинается с буквы, точки или `..` — относительно текущей позиции.
```bash
cd Documents          # папка Documents внутри текущей
cd ../Pictures        # соседняя папка Pictures
cd ../../var          # подняться на 2 уровня, затем зайти в var
```

## ⚙️ Полезные приёмы

### Автодополнение (Tab)
Начните вводить имя папки и нажмите `Tab` — терминал сам дополнит или покажет варианты.

### `cd` с переменными
```bash
cd $HOME
cd $OLDPWD           # то же, что cd -
```

### Проверить, где вы находитесь
Команда `cd` не выводит результат. Узнать текущую папку можно так:
```bash
pwd                  # print working directory
```

## 🚫 Ошибки и их причины

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `bash: cd: xxx: No such file or directory` | Папка не существует | Проверьте имя и путь через `ls` |
| `Permission denied` | Нет прав на вход в папку | Используйте `sudo cd`? (не сработает). Нужно либо сменить права, либо зайти от root: `sudo -i` |
| `Not a directory` | Вы пытаетесь зайти в файл, а не в папку | Проверьте тип через `ls -l` |

## 🧩 Полезные псевдонимы (alias)

Добавьте в `~/.bashrc` или `~/.zshrc`:

```bash
alias ..='cd ..'
alias ...='cd ../..'
alias ....='cd ../../..'
alias back='cd -'
alias home='cd ~'
```

## 🔄 Разница между `cd` и `cd ~`

В большинстве случаев — никакой. Оба ведут в домашнюю папку.

Но:
- `cd` → домой (переменная `$HOME`)
- `cd ~username` → домой пользователя `username`

## 📋 Краткая шпаргалка

| Действие | Команда |
|----------|---------|
| Перейти в домашнюю папку | `cd` |
| Перейти в корень | `cd /` |
| На уровень выше | `cd ..` |
| На два уровня выше | `cd ../..` |
| Вернуться в прошлую папку | `cd -` |
| В папку с пробелом | `cd "Имя папки"` |

## 🧠 Особенности (важно!)

1. **`cd` не выводит ничего** при успехе — это нормально.
2. **`cd -`** выводит путь, в который вы перешли.
3. **Нельзя `cd` в файл** — только в директорию.
4. **`cd` работает только в текущей сессии терминала** — не влияет на другие вкладки или скрипты (если не использовать `exec` или `source`).

## 🐚 В скриптах

В bash-скрипте `cd` меняет папку **только внутри скрипта**, если только вы не выполните скрипт через `source`:

```bash
# Запуск скрипта
./myscript.sh          # cd внутри него НЕ изменит вашу текущую папку

# Запуск с source (или .)
source myscript.sh     # cd внутри ИЗМЕНИТ вашу папку
. myscript.sh          # то же самое
```

## 📚 Справка

```bash
help cd          # встроенная справка bash
man cd           # не сработает (cd — встроенная команда)
type cd          # покажет, что cd встроена в оболочку
```
```
