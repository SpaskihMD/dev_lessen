# 🕐 Изменение времени файла в Linux

В Linux каждый файл имеет несколько меток времени. Команда `touch` позволяет изменять их вручную.

## 📊 Три типа времени файла

| Тип | Полное название | Что означает | Когда меняется |
|-----|----------------|--------------|----------------|
| **mtime** | Modification time | Время изменения *содержимого* файла | При редактировании, записи, перезаписи |
| **ctime** | Change time | Время изменения *метаданных* (права, владелец, имя) | При `chmod`, `chown`, `mv`, а также при изменении содержимого |
| **atime** | Access time | Время последнего *чтения* файла | При `cat`, `less`, `grep` (чтении) |

> ⚠️ **Важно:** `ctime` нельзя изменить вручную — только системой. `mtime` и `atime` — можно.

## 🔧 Команда `touch` — основной инструмент

### Базовый синтаксис
```bash
touch [опции] имя_файла
```

### Что делает `touch` без опций?
- Если файл **не существует** — создаёт пустой файл.
- Если файл **существует** — обновляет `atime` и `mtime` на текущее время (ctime тоже обновится автоматически).

## 📌 Примеры изменения времени

### 1. Обновить все времена на текущие
```bash
touch file.txt
```

### 2. Установить конкретную дату и время
```bash
# Формат: [[CC]YY]MMДДhhmm[.сс]
touch -t 202512312359.59 file.txt
# 31 декабря 2025 года, 23:59:59
```

### 3. Установить только mtime (оставив atime как есть)
```bash
touch -m -t 202501011200 file.txt
```

### 4. Установить только atime
```bash
touch -a -t 202501011200 file.txt
```

### 5. Использовать метку времени другого файла
```bash
# Скопировать времена с reference.txt на file.txt
touch -r reference.txt file.txt
```

### 6. Установить дату из переменной
```bash
touch -d "2024-01-15 14:30:00" file.txt
touch -d "2 days ago" file.txt
touch -d "last monday" file.txt
```

## 🎯 Продвинутые примеры с `-d`

```bash
# Человеко-читаемые форматы
touch -d "2024-03-20" file.txt
touch -d "2024-03-20 15:30" file.txt
touch -d "yesterday" file.txt
touch -d "next week" file.txt
touch -d "1 hour ago" file.txt
touch -d "last friday 10pm" file.txt
```

## 📋 Полезные опции `touch`

| Опция | Что делает |
|-------|-------------|
| `-a` | Меняет только **atime** (время доступа) |
| `-m` | Меняет только **mtime** (время модификации) |
| `-t` | Устанавливает время в формате `[[CC]YY]MMДДhhmm[.сс]` |
| `-d` | Устанавливает время в человеко-читаемом формате |
| `-r` | Копирует времена из другого файла |
| `-c` | Не создавать файл, если его нет (`--no-create`) |
| `-h` | Работать с символьной ссылкой, а не с целевым файлом |

## 🔍 Как посмотреть времена файла

```bash
# Простой список (только mtime)
ls -l file.txt

# Полная информация (atime, mtime, ctime)
stat file.txt

# Только mtime
ls -l --time-style=full-iso file.txt

# Сортировка по времени
ls -lt              # по mtime (новые сверху)
ls -ltu             # по atime
ls -ltc             # по ctime
```

## 📊 Пример вывода `stat`

```bash
$ stat file.txt
  File: file.txt
  Size: 1024        Blocks: 8          IO Block: 4096   regular file
Access: 2024-03-20 15:30:00.000000000 +0300   # atime
Modify: 2024-03-20 15:30:00.000000000 +0300   # mtime
Change: 2024-04-07 12:34:56.123456789 +0300   # ctime (меняется при любом изменении)
```

## 🧪 Практические примеры

### Изменить дату всех файлов в папке
```bash
# Все файлы в текущей папке получили текущее время
touch *

# Рекурсивно все файлы и папки
find . -type f -exec touch -t 202401011200 {} \;
```

### Сделать файл "старше" (обмануть проверки)
```bash
# Установить дату год назад
touch -d "1 year ago" old_file.txt
```

### Синхронизировать времена нескольких файлов
```bash
touch -r source.txt dest1.txt dest2.txt dest3.txt
```

## ⚠️ Важные нюансы

1. **ctime изменить нельзя** — оно всегда становится текущим при любом изменении файла (включая `touch`).
2. **Для изменения времени нужны права на запись** в файл (или быть владельцем).
3. **`touch` на несуществующий файл** — создаст его (если нет `-c`).
4. **Файловые системы могут не поддерживать atime** (например, `noatime` в `/etc/fstab`).
5. **Микросекунды** — современные файловые системы хранят наносекунды, `touch` с `-t` ставит только секунды.

## 📋 Краткая шпаргалка

| Задача | Команда |
|--------|---------|
| Обновить время на "сейчас" | `touch file` |

| Человеко-читаемая дата | `touch -d "2024-03-20 15:30" file` |
| Скопировать время с другого файла | `touch -r source dest` |
| Не создавать файл, если его нет | `touch -c file` |
| Посмотреть все времена | `stat file` |
